# Bank Transactions BookKeeping

A professional, 100% client-side web application for managing bank transactions and bookkeeping. This tool is designed to provide a premium, desktop-like experience for tracking financial activity across multiple accounts.

## Features

- **Dashboard Overview**: Visual overview of your financial health with interactive charts.
- **Transaction Management**: Easily add, edit, and categorize transactions (Credit/Debit).
- **Account Tracking**: Manage multiple bank accounts in one place.
- **Receipt Generation**: Create and export professional PDF receipts for transactions.
- **Financial Statements**: Generate detailed bank statements and reports.
- **Offline First**: All data is stored securely on your local device using browser storage (IndexedDB).
- **Responsive Design**: Works seamlessly on both desktop and mobile devices.

## Technology Stack

- **Frontend**: HTML5, Vanilla CSS, JavaScript.
- **Storage**: IndexedDB (Local Storage).
- **PDF Generation**: HTML2Canvas, jsPDF.

## Getting Started

1.  Clone the repository:
    ```bash
    git clone https://github.com/[YOUR_USERNAME]/Bank-Transections-BookKeeping.git
    ```
2.  Open `index.html` in your browser or use a local dev server.
